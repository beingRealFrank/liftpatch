Drupal 11 system requirements

Drupal 11 needs PHP 8.3 or newer. Most failed Drupal 11 upgrades start with the server, not the code, so check these first.

The requirements

PHP8.3 or newer
MySQL8.0
MariaDB10.6
PostgreSQL16
SQLite3.45
Drush13
Composer2.7 or newer
Starting Drupal version10.3 or later

Confirm against the official system requirements on drupal.org before you commit, because minor releases can raise a minimum.

Check what you have

php -v
composer --version
drush --version
drush status --fields=drupal-version,db-driver,php-version

Common problems

  • PHP 8.1 or 8.2 on the host. Drupal 10 ran on those, Drupal 11 will not. Raise the PHP version in staging first; some old modules and libraries break on 8.3, which is separate from the Drupal upgrade.
  • Drush 12 or older. Update with composer require drush/drush:^13. Run it from the project, not a global install.
  • A managed host that pins PHP. Look for the PHP setting in your hosting dashboard, and ask support what the deadline for changing it is.
  • Core older than 10.3. Move to the latest 10.x first. See the step-by-step guide.
