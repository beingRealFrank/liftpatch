Drupal core modules removed in Drupal 11

Six modules that shipped in Drupal 10 core are not in Drupal 11 core: Action UI, Book, Forum, Statistics, Tour and Activity Tracker. If any are enabled on your site, you must switch to the contributed version before you move core to 11, or the upgrade will fail or lose functionality.

Check what's enabled

drush pm:list --status=enabled --type=module | grep -E "action|book|forum|statistics|tour|tracker"

The free scanner also asks which of these you use and adds each to your quote.

What to do for each

ModuleWhat it didWhat to do
Action UIAdmin interface for configurable actionsInstall the contrib project of the same name while still on Drupal 10, then confirm your actions still appear.
BookHierarchical book outlinesInstall the contrib Book project; check outlines and navigation blocks after.
ForumDiscussion forumsInstall the contrib Forum project, or migrate to a dedicated forum tool if usage is low.
StatisticsContent view countersInstall the contrib project, or replace with an analytics service; stored view counts are in the database.
TourGuided admin toursInstall the contrib project if editors rely on tours; otherwise uninstall.
Activity TrackerRecent-activity listingsInstall the contrib project, or rebuild the view if you only need a recent-content list.

The safe order

  1. On Drupal 10, composer require drupal/<module> for the contrib replacement. Because it has the same machine name, the enabled state and configuration carry over.
  2. Verify the feature in staging.
  3. Only then move core to 11. Composer errors?

Confirm names and the exact project pages on drupal.org before you start, since projects get renamed and maintainers change. Check each one in the atlas as well.
