Adminimal theme on Drupal 11: moving to Claro

The atlas shows drupal/adminimal_theme and drupal/adminimal_admin_toolbar with no Drupal 11 release (their latest versions declare support for Drupal 10 and earlier). Sites using them for the admin interface need another admin theme before they can move core to 11.

Check what you use

drush config:get system.theme admin
composer show "drupal/adminimal*"

The replacement path

  1. Switch to Claro. Claro is core's administration theme in Drupal 10 and 11. At /admin/appearance, set Claro as the administration theme and check the content, media and views admin pages.
  2. Replace the toolbar. If you used Adminimal Admin Toolbar, install the contributed drupal/admin_toolbar module, which provides the dropdown menu and is maintained for Drupal 11 (check its project page for the version).
  3. Move customisations. Any CSS you added to the Adminimal theme must be reapplied via a small admin-facing module or sub-theme of Claro.
  4. Remove the old packages with composer remove drupal/adminimal_theme drupal/adminimal_admin_toolbar once nothing references them, and clear caches.
  5. Then update core.

This is a visual change for your editors, so tell them before it ships and check any custom forms in the new theme. Use the scanner for the cost of each blocker in your own lock file.
