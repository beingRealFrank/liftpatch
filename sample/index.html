This is a real run of our pipeline on a test site we built to look like a typical client site, so you can see the evidence before you order.

What you receive

  • A pull request, or 4 git am-ready patches, split into two releases. Drupal 11 only updates databases already on 10.3+, and CKEditor 4 must be uninstalled while its code is still present.
  • A deploy runbook covering server requirements, backups, the exact commands for each release, what to check afterwards, and rollback.
  • The verification logs. See the final Drupal 11 verification log from this run.
  • An example patch: custom code moved to Drupal 11 APIs and CKEditor 4 → 5.
