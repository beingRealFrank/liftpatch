How much does a Drupal 10 to 11 upgrade cost?

For a typical small site (core plus 20 to 40 contributed modules and one or two custom modules), expect roughly $1,500 to $2,500 as a fixed price, or one to three developer-days if you do it yourself. Sites with abandoned modules, heavy custom code or old themes cost more. The price is driven by a short list of things you can measure in ten minutes.

What moves the price

  • Contributed modules that already support Drupal 11. These are mostly a version bump and a test run. Cheap.
  • Modules that need a major-version jump. The module changed its configuration or API between versions, so the update needs checking and sometimes a config migration.
  • Modules with no Drupal 11 release. This is the biggest cost driver. Options are a community compatibility patch from the issue queue, writing one, or replacing the module. Each is real work.
  • Core modules that left core (Action UI, Book, Forum, Statistics, Tour, Activity Tracker). Each becomes a contrib module you must install and verify. Details here.
  • Custom modules and themes. Cost scales with the amount of code and with how many deprecated APIs it calls. A theme on a removed base theme (Classy, Stable, Seven, Bartik) needs a real fix.
  • Your starting version. Drupal 11 needs you on 10.3 or later first. Older sites pay for the catch-up.
  • Testing. A site with an automated test suite is faster and safer to upgrade than one that needs manual verification.

What it costs to do it yourself

If you have a Drupal developer, the cost is their time. Plan on a day to measure and fix a small site with Upgrade Status and Rector, plus extra days for each module with no Drupal 11 release and for custom code. The end-of-life guide lists the exact commands. Rector and Upgrade Status are free; the expensive part is whoever reviews the diff and tests the site.

The cost of waiting

After December 9, 2026 Drupal 10 gets no more security releases. Quotes from agencies tend to rise and calendars fill as the date approaches, so the cheapest time to get a firm price is now.
