Upgrading from Drupal 10

Options: apply a community compatibility patch from the issue queue (often found by searching "Drupal 11" in the project's issues), port the module, or replace it with a maintained alternative.

Composer line and checks

Only a pre-release supports Drupal 11: composer require drupal/migrate_file:3.0.0-alpha1 (set minimum-stability for this package only, and test it first).

Run Upgrade Status and Drupal Rector against your own code that uses migrate_file. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.

Look for a Drupal 11 compatibility issue: search the migrate_file issue queue for "Drupal 11".
