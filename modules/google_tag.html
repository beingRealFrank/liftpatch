Is google_tag compatible with Drupal 11?

Yes. google_tag supports Drupal 11 from version 2.0.6.

Upgrading from Drupal 10

While you're still on Drupal 10, update google_tag to 2.0.9 with composer require drupal/google_tag:^2.0. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/google_tag:^2.0 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses google_tag. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
