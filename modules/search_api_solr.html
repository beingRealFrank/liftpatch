Is search_api_solr compatible with Drupal 11?

Yes. search_api_solr supports Drupal 11 from version 4.3.2.

Upgrading from Drupal 10

While you're still on Drupal 10, update search_api_solr to 4.3.14 with composer require drupal/search_api_solr:^4.3. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/search_api_solr:^4.3 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses search_api_solr. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
