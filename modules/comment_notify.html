Is comment_notify compatible with Drupal 11?

Yes. comment_notify supports Drupal 11 from version 1.5.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update comment_notify to 1.6.0 with composer require drupal/comment_notify:^1.6. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/comment_notify:^1.6 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses comment_notify. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
