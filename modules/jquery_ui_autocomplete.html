Is jquery_ui_autocomplete compatible with Drupal 11?

Yes. jquery_ui_autocomplete supports Drupal 11 from version 2.1.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update jquery_ui_autocomplete to 2.1.0 with composer require drupal/jquery_ui_autocomplete:^2.1. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/jquery_ui_autocomplete:^2.1 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses jquery_ui_autocomplete. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
