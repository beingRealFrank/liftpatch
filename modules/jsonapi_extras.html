Is jsonapi_extras compatible with Drupal 11?

Yes. jsonapi_extras supports Drupal 11 from version 3.26.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update jsonapi_extras to 3.28.0 with composer require drupal/jsonapi_extras:^3.28. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/jsonapi_extras:^3.28 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses jsonapi_extras. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
