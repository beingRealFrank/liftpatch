Is inline_entity_form compatible with Drupal 11?

Yes. inline_entity_form supports Drupal 11 from version 3.0.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update inline_entity_form to 3.0.0 with composer require drupal/inline_entity_form:^3.0. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/inline_entity_form:^3.0 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses inline_entity_form. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
