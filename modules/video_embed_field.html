Is video_embed_field compatible with Drupal 11?

Yes. video_embed_field supports Drupal 11 from version 3.0.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update video_embed_field to 3.1.1 with composer require drupal/video_embed_field:^3.1. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/video_embed_field:^3.1 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses video_embed_field. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
