Upgrading from Drupal 10

While you're still on Drupal 10, update password_policy to 4.0.3 with composer require drupal/password_policy:^4.0. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/password_policy:^4.0 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses password_policy. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
