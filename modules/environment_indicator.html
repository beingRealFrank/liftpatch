Is environment_indicator compatible with Drupal 11?

Yes. environment_indicator supports Drupal 11 from version 4.0.19.

Upgrading from Drupal 10

While you're still on Drupal 10, update environment_indicator to 4.0.25 with composer require drupal/environment_indicator:^4.0. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/environment_indicator:^4.0 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses environment_indicator. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
