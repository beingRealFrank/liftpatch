Upgrading from Drupal 10

While you're still on Drupal 10, update key to 1.23.0 with composer require drupal/key:^1.23. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/key:^1.23 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses key. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
