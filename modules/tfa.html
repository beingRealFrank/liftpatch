Is tfa compatible with Drupal 11?

Yes. tfa supports Drupal 11 from version 1.9.0.

Upgrading from Drupal 10

While you're still on Drupal 10, update tfa to 1.13.0 with composer require drupal/tfa:^1.13. Then run drush updb. That release works on both 10 and 11, so it won't block the core upgrade.

Composer line and checks

composer require drupal/tfa:^1.13 on Drupal 10, then drush updb.

Run Upgrade Status and Drupal Rector against your own code that uses tfa. Rector fixes many removed or deprecated API calls automatically; calls it can't rewrite, and any custom code touching this module's APIs, need a manual fix.
