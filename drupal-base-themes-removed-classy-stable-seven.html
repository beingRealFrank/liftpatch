Classy, Stable, Seven and Bartik in Drupal 11

Custom themes that declare base theme: classy, stable, seven or bartik are a common Drupal 11 blocker, because those themes are no longer shipped in Drupal 11 core. A theme that depends on a missing base theme will not install.

Find affected themes

grep -rE "base theme:\s*(classy|stable|seven|bartik)\b" web/themes/custom --include=*.info.yml

The free scanner runs the same check when you choose your project folder (files are read in the browser only) and adds each affected theme to your quote.

Your options

  1. Install the contrib version of the base theme. The removed core themes were moved to contributed projects of the same names, so the quickest route is composer require drupal/classy (or the matching project) while you are on Drupal 10, then verify the site. Check the project's page for a Drupal 11 release before you rely on it.
  2. Rebase onto a new theme. Generate a fresh theme from core's Starterkit and move your templates, libraries and CSS across. More work, and you stop depending on an old base.
  3. Copy the base templates you actually use into your theme and remove the base theme line. Good when you only used a handful of Classy templates.

Test the look, not just the install

Base themes supply markup and CSS classes. When one changes, spacing, forms and admin pages can shift. Compare key pages before and after in staging. Then move core.
