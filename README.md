# Liftpatch: Drupal 10 → 11 readiness scan and fixed quote

https://beingrealfrank.github.io/liftpatch/

Paste a `composer.lock` and get each contrib project's Drupal 11 status, the version to move to, and a fixed price for the upgrade. Everything runs in the browser. The only network calls go to `packages.drupal.org` for public release metadata, and the page's Content-Security-Policy enforces that.
