We checked 212 popular Drupal modules for Drupal 11 support

191 of 212 have a stable release that supports Drupal 11. 15 have only an alpha, beta or release candidate, and 6 have no Drupal 11 release at all. Data from packages.drupal.org, checked 2026-11-14. Drupal 10 security support ends December 9, 2026.

Method

For each module in the Liftpatch atlas we read its Composer release metadata from packages.drupal.org and looked for the newest release whose drupal/core constraint allows Drupal 11. A release counts as stable if its version has no alpha, beta, rc or dev suffix. The atlas covers popular modules and themes, not every project on drupal.org, so treat the numbers as a guide, not a census.
